# P14.4 — human PK validation status

The validation registry is deliberately a blocked-result report, not a claim
of clinical validation:

- **Fentanyl:** human three-compartment source literature exists, but no single
  verified parameter set has been transcribed.
- **Haloperidol:** no readable verified human two-compartment population set is
  available; no depot population model is asserted.
- **Diazepam:** no adult population PK model is available in the reviewed set;
  pediatric/methodological models are not substituted for adults.

The registry records Johnson et al. 2016 (PMID 26718955) as a known failure
mode: a rat hybrid PBPK-PD transfer under-predicted human D2 occupancy because
brain reduced-haloperidol back-oxidation and active BBB influx were unmodelled.
This is a regression constraint against treating cross-species PK transfer as
validated.

Independent published curve comparisons remain required before any of these
models can be used as a human clinical predictor.

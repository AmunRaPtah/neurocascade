# P17.2 — Effector-specific human `ke0`

The human layer now has explicit effect-site equilibration records for
cognitive performance, motor activity, subjective sedation, and anxiety state.
Each record stores an effector-specific `ke0` in min⁻¹ and derives its
associated effect-site half-life.

`ke0` is intentionally separate from systemic elimination: it represents the
delay between brain exposure and an observed endpoint. Current values are
clearly labelled illustrative priors because matched human effect-site data
have not yet been fitted. They must not be interpreted as clinical estimates
or used to replace human dose-response validation.

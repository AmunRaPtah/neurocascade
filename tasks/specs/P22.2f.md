Implement the P22.2 scoring rules from docs/p22-preregistration.md
("Metrics and pass criteria, fixed now", and convention C5) as pure functions
in a new module `src/neurocascade/human/label_dose_scoring.py`. No PK, no
drug data, no I/O: this module only compares two dose intervals.

API (names are fixed by the tests):

- `round_sig(x: float, sig: int = 3) -> float` rounds to `sig` significant
  figures (C5: doses are evaluated at 3 significant figures).
- `@dataclass(frozen=True) class Score` with fields
  `drug: str`, `overlap: bool`, `e: float | None`, `passed: bool`,
  `refusal: str | None`.
- `score(drug, d65, d78, l_low, l_high) -> Score`:
  - `d65`/`d78` may be `None`, meaning that occupancy target is unreachable.
    Then overlap is False, `e` is None, passed is False, and `refusal` is
    None (an unreachable window is a scored failure, not a refusal).
  - Otherwise round all four doses with `round_sig` first, then:
    overlap = closed-interval intersection of [d65, d78] and
    [l_low, l_high] (touching at an endpoint counts).
    e = log10( sqrt(d65*d78) / sqrt(l_low*l_high) ).
    passed = overlap and |e| <= log10(2), with a 1e-12 tolerance so an exact
    boundary case passes.
  - Raise `ValueError` if any given dose is <= 0, or d65 > d78, or
    l_low > l_high.
- `refused(drug, layer: str) -> Score`: a drug that could not be scored.
  overlap False, e None, passed False, refusal = layer (non-empty, else
  ValueError).
- `aggregate(scores: list[Score], denominator: int = 8) -> dict` with keys
  `n_pass`, `n_scored` (scores whose refusal is None, including unreachable
  ones), `denominator`, `median_abs_e` and `max_abs_e` (over scores with a
  non-None e; None if there are none), and `per_drug` = {drug: e}.
  Raise `ValueError` if drug names repeat or there are more scores than
  the denominator.

There are no scientific constants in this task. The only numbers are
log10(2) and the 3 significant figures, both from the pre-registration.
